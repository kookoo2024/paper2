# 知学网阅卷助手

AI自动批改主观题，支持自动提交分数。

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 准备配置
把 `zhixue_simple_config.example.json` 复制为 `zhixue_simple_config.json`（该文件已被 .gitignore 忽略，**API Key 只放这里，千万不要提交到 GitHub**）。

### 3. 运行程序
- **推荐**：双击 `start.pyw`（不弹黑窗口）；或运行一次 `make_shortcut.bat`，以后点桌面的「阅卷」。
- 调试时用 `python zhixue_simple.py`（带命令行窗口，能看到报错）。
- 无窗口模式下的报错写在 `run.log`。

## 使用步骤

### 首次使用（需要设置）

1. **设置答案区域**
   - 点击「框选」按钮
   - 拖动鼠标框选学生答案区域

2. **输入题目信息**
   - 题号：如 17
   - 满分：如 15
   - 参考答案：手动输入或点击「截图识别」

3. **设置自动提交**
   - 点击「定位」按钮
   - 按提示依次设置：分数输入框位置、提交按钮位置

4. **测试功能**
   - 点击「测试」按钮
   - 检查是否正确输入分数并点击提交

### 日常使用（自动记忆）

程序会自动记忆上次的设置，直接使用即可：

1. **安全模式**（需要确认）
   - 勾选：✓ 连续 + ✓ 自动填分
   - 按空格键开始批改
   - 每次弹窗确认分数（Enter接受 / Esc拒绝）
   - 效率：500-700份/小时

2. **高效模式**（跳过确认）⚡
   - 勾选：✓ 连续 + ✓ 自动填分 + ✓ 跳过确认
   - 按空格键开始批改
   - 自动提交，无需确认
   - 效率：900-1200份/小时

## 接入本机 Magpie（推荐）

[magpie](https://usemagpie.ai) 是本机的模型网关（127.0.0.1:3425），在 magpie 里配好 Gemini / DeepSeek / Qwen / Ollama 等，本程序只连 magpie 一个地址，Key 都留在 magpie 里。

1. 打开 magpie 应用（或命令行 `magpie serve`），在里面添加至少一个**能识图**的模型（如 Gemini 2.5 Flash、Qwen-VL）
2. 本程序点「模型设置」→ 提供商选 **Magpie** → 自动检测并获取模型列表
3. 选一个能识图的模型 → 保存。API Key 默认 `magpie-zhixue`（本机任意值都行，用来在 magpie 的 Usage 里区分本程序的调用）

## 在线更新

- 程序启动 3 秒后会静默检查一次，有新版本时右上角 ⬆ 变红「⬆新」；也可以随时点 ⬆ 手动检查
- 更新源：GitHub 原始地址，连不上自动换 jsDelivr 镜像；可在配置里加 `"update_url": "你的地址/"` 改成自己的服务器
- 只下载 `version.json` 里列出的文件，逐个校验 sha256 和语法，**绝不覆盖你的配置文件**；旧文件备份在 `backup/` 文件夹
- 不想自动检查：配置里加 `"auto_check_update": false`

**发布新版本**（开发者）：改 `APP_VERSION` → 运行 `python make_release.py` 重新生成 `version.json` → 提交推送到 main。

## 快捷键

- `空格` - 开始批改
- `Esc` - 停止批改
- `Enter` - 确认分数（确认对话框中）
- `Esc` - 拒绝分数（确认对话框中）

## 暂停与继续

在自动连续批改模式下：
- 点击"⏸ 暂停"按钮可以暂停批改
- 点击"▶ 继续"按钮可以继续批改
- 暂停后不会影响当前正在批改的试卷
- 适合需要临时处理其他事务的场景

## 注意事项

1. 首次使用需要设置答案区域和自动提交位置
2. 设置完成后会自动保存，下次启动自动加载
3. 修改题目信息后会自动保存
4. 建议先用"安全模式"测试几份，确认无误后再用"高效模式"
5. 使用"高效模式"时请确保AI批改准确率高

## 技术支持

- 默认走本机 Magpie（`workbuddy/deepseek-v4.1-flash`，单题约 3-5 秒）；Magpie 不可用时自动回退 Gemini
- Gemini 免费额度用尽会自动切 Magpie，不再卡在“key 全部冷却”
- 单题请求硬上限 15 秒，目标总耗时 <20 秒；超时会直接中止并提示换模型
- 自动识别学生答案并对比参考答案
- 按给分点逐条得分，显示每条得分/满分和理由
- 支持自动点击和输入功能

## 配置文件

- `zhixue_simple_config.json` - 保存所有设置和题目信息
- 可手动编辑或删除重新设置


## 批改准确性（v1.3.0）
- **给分点**：点 ② 里的「编辑答案」打开大窗口，左边写参考答案，右边写给分点，每行一条：`求出斜率 k=2｜2分`。参考答案里写了「（2分）」的，可点「从答案提取」自动生成。不填时模型会先从参考答案里拆出给分点。
- **按点得分**：模型逐条给分，总分由程序相加（不再用“满分减扣分”），并按「可给0.5」取整。
- **先转写再判分**：结果区显示模型识别出的学生原文，看错字一眼能发现；看不清会标【看不清】。
- **强制人工确认**：把握度低、有看不清、用了其他解法、给分点合计≠满分、模型总分与逐点相加不一致时，即使勾了跳过确认也会弹窗。
- **空白卷**：答题区域几乎没有墨迹时直接判 0 分，不调用模型（阈值 `blank_threshold`，默认 0.0015，可在配置文件里改）。
- 截图四周自动多留 6 像素，避免切掉边上的字。

## v1.7.0 修复（2026-11-11）

- **新评分逻辑真正接上**：以前 `build_grading_prompt` / `settle_score` 是死代码，实际还在用“满分减扣分”的旧提示词，分数才会忽高忽低。现在改为逐给分点给分，程序相加，合计不等于满分会强制复核。
- **自动拆给分点**：参考答案末尾写「……5分」「……15分」时，程序自动按累计分拆成 5 + 2 + 8，并让模型严格按这三条判。也可以在「编辑答案」里手动改。
- **Gemini 额度兜底**：免费档常见 20 次/天/项目，多个 key 同项目共用。额度用尽会立刻切本机 Magpie，不再等冷却。
- **截图预览**：① 区新增「预览」，④ 区显示本次截图缩略图；截到课程表、黑屏、遮挡时能马上发现。截图几乎全黑会直接停止。
- **分数可改**：确认弹窗里分数是输入框，AI 给错直接改，回车提交，不用先拒绝再手输。
- **批改时临时取消置顶**：自动填分时不再用 360 宽的小窗挡住分数输入框；顶栏「置顶」可手动开关。
- **自动填分改用粘贴**：避免中文输入法/小数点导致输入错误；提交按钮只点一次，避免重复提交。
- **去掉停止维护的 `google.generativeai` SDK**，全部改 REST，启动不再报 FutureWarning。

## v1.7.3（2026-11-11）

- **给分点不再被截断**：以前自动拆出的给分点只保留 28～40 字，`解得 k=15/8`、`EF 方程 x+4y+12=0` 这类关键结论会被截掉，模型只能凭印象给分。现在保留每个分问的起点和最终结论，按你给的评分标准逐条对照。
- **手动粘贴的给分点也能认**：像“求出直线 AB 的方程 15x−8y−55=0（2分）”这种超过 20 字的长给分点，现在也能识别；“本题满分 15 分”“参考答案共 15 分”这类汇总说明不会被误当成给分点。
- **评分更严格**：写出该点要求的公式、方程或结论才给分；只写思路、没算出结果最多给一半；该点结论错误不得给满；拿不准时按未完成处理，不替学生补步骤。
- **等价解法不再误判 0 分**：第(2)问用切点弦/极点极线直接写 `(x₀−a)(x−a)+(y₀−b)(y−b)=r²`，和“四点共圆、两圆相减”同样给分。
- **自动裁掉截图底部的 Windows 任务栏**：任务栏图标会干扰识图；程序只在底部整段“又暗又彩”时裁掉，白底手写和纯黑图不会误裁。
- **多次判分改为取中位数**：每份固定判 3 次，取中间分，不再取最高分，减少“越判越松”。
- 单份实测约 9～10 秒，仍在 20 秒以内。

## v1.7.4（2026-11-11）

- **只判一次**：取消“每份判 3 次取中位数”，每份只请求一次模型，判完即用，更快也更省额度。
- **严格按给分点给分**：只有写出该点要求的公式、方程或结论（或数学上等价的正确表达）才给分；没看到得分点、也没有等价表达，或只写思路、跳步、结论写错，一律 0 分，不再给“思路分/步骤分/同情分”。
- **不许模型改分值**：返回的给分点条数和分值必须与评分标准一致，模型改动会被程序回填并提示复核。
- **取整只向下**：不再四舍五入凑分，例如 12.5 分按 12 分计。
- **取消逐份人工复核**：把握度低、看不清、等价解法等情况不再强制弹窗，判完直接提交；“跳过确认”默认勾选，需要把关时可手动取消。
- 「参考答案」编辑窗口新增「粘贴」按钮：剪贴板文字一键填入或追加，图片请用「截图识别」。
