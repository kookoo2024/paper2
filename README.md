# 知学网阅卷助手

AI自动批改主观题，支持自动提交分数。

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行程序
```bash
python zhixue_simple.py
```

## 使用步骤

### 首次使用（需要设置）

1. **设置答案区域**
   - 点击"📷 设置"按钮
   - 拖动鼠标框选学生答案区域

2. **输入题目信息**
   - 题号：如 17
   - 满分：如 15
   - 参考答案：手动输入或点击"📷"截图识别

3. **设置自动提交**
   - 点击"⚙设置"按钮
   - 按提示依次设置：分数输入框位置、提交按钮位置

4. **测试功能**
   - 点击"🧪测试"按钮
   - 检查是否正确输入分数并点击提交

### 日常使用（自动记忆）

程序会自动记忆上次的设置，直接使用即可：

1. **安全模式**（需要确认）
   - 勾选：✓ 自动连续 + ✓ 自动点击
   - 按空格键开始批改
   - 每次弹窗确认分数（Enter接受 / Esc拒绝）
   - 效率：500-700份/小时

2. **高效模式**（跳过确认）⚡
   - 勾选：✓ 自动连续 + ✓ 自动点击 + ✓ 跳过确认
   - 按空格键开始批改
   - 自动提交，无需确认
   - 效率：900-1200份/小时

## 快捷键

- `空格` - 开始批改
- `Esc` - 停止批改
- `Enter` - 确认分数（确认对话框中）
- `Esc` - 拒绝分数（确认对话框中）

## 暂停与继续

在自动连续批改模式下：
- 点击"⏸ 暂停"按钮可以暂停批改
- 点击"▶ 继续"按钮可以继续批改
- 暂停后不会影响当前正在批改的试卷
- 适合需要临时处理其他事务的场景

## 注意事项

1. 首次使用需要设置答案区域和自动提交位置
2. 设置完成后会自动保存，下次启动自动加载
3. 修改题目信息后会自动保存
4. 建议先用"安全模式"测试几份，确认无误后再用"高效模式"
5. 使用"高效模式"时请确保AI批改准确率高

## 技术支持

- 使用 Gemini 2.5 Flash 模型进行AI批改
- 自动识别学生答案并对比参考答案
- 详细扣分分析和评语
- 支持自动点击和输入功能

## 配置文件

- `zhixue_simple_config.json` - 保存所有设置和题目信息
- 可手动编辑或删除重新设置
